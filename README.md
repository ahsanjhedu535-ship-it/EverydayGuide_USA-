# EverydayGuide USA — Premium Knowledge Base

20 article pages, 4 topic categories, search, two simple tools, local SVG illustrations, responsive premium UI, metadata, sitemap and robots files.

## Run
npm install
npm run dev

## Deploy
Import this folder/repository into Vercel as a Next.js project.

## Before launch
Replace YOUR-DOMAIN.com in app/sitemap.js and app/robots.js, connect Google Search Console, review the legal pages for your exact services, and add authoritative references to high-stakes topics where appropriate.
